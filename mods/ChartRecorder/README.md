# MUSYNX 敲谱曲库 Mod · 0.2.0

适配本机验证的 **Steam 原版 MUSYNX，Build 25570400 / Unity 2017.4.4f1**。这是固定使用《蜡烛人》槽位的本地制谱测试 Mod。

## 使用

关闭游戏后安装。正常从 Steam 启动 MUSYNX；如果出现原游戏的启动配置窗口，像平时一样点击进入游戏。在选歌界面按 **F8**，或点击右上角 **敲谱曲库**。

1. 点击 **导入歌曲与谱面**，先选择对应的本地 **MP3 / WAV** 音乐，再选择敲谱器导出的 **JSON**。
2. 左侧切换歌曲，右侧切换该歌曲的谱面。选中项自动保存，下次启动会恢复。
3. **添加本曲的另一张谱面** 可导入同一音乐的另一份 JSON，方便对比不同版本。
4. 可以试听当前歌曲、调节自定义音乐音量。点击 **进入官方开歌设置 · 4 键**。在官方界面调速度、显示／判定补偿，点击 **主题设置** 选择游戏原有的 2D／3D、主题和细节，再点击原版 **开始**。也可以通过原菜单的蜡烛人入口游玩当前选择。
5. 曲库底部 **打击音** 可选关闭、原版切换音、原版确认音，支持音量与试音。有效命中的单点／长条头触发一次，多押逐音符触发；长条持续段不重复播放。设置自动保存。
6. 每张谱面显示最高／上次同步率；点击 **成绩详情** 查看最近 20 局的同步率、最大连击、EX／EXACT／GREAT／RIGHT／MISS、时间及游玩场景。总游玩次数持续累计。
7. **切回蜡烛人原曲** 恢复该槽位的原曲和原谱。

单点、多押和长条来自 JSON 中的实际时间。使用完整歌曲作为背景音乐，可选择统一的原版反馈音，尚不支持为每个音符指定不同乐器 Key 音。打歌中使用游戏原有暂停、续播、重开和返回；换歌、换谱在选歌界面进行。

支持本项目 `version:1 / keys:4` 格式，1–20000 个音符、最长 10 分钟、3 MB JSON、100 MB 原始音乐。BPM 范围 30–300。转换后的 PCM WAV 和谱面一起保存，原文件之后移动不会影响曲库。自定义谱的成绩不写入蜡烛人的本地成绩或排行榜。

包中包含两首本项目合成的示例音乐；其中第一首有两张谱面。首次安装且没有现有曲库时才添加示例。

## 安装、卸载和数据

解压完整安装包，双击 **安装.bat**。脚本会查找 Steam 原版 MUSYNX，核对文件版本并备份后安装。若有多个安装目录，可在 PowerShell 中明确指定：

```powershell
.\Install.ps1 -Mode Install -GameRoot 'E:\SteamLibrary\steamapps\common\MUSYNX'
.\Install.ps1 -Mode Status -GameRoot 'E:\SteamLibrary\steamapps\common\MUSYNX'
```

关闭游戏后双击 **卸载.bat**，恢复原程序集和音频设置。自定义曲库保留在游戏目录的 `CustomCharts/Library/`。该目录包含歌曲、谱面和 `library.json`，分享自制谱时需要整份保留。本机成绩及打击音设置单独保存在 `CustomCharts/scores.json`，以歌曲与谱面的独立 ID 绑定；备份个人数据时一起复制，分享时可不包含个人成绩。重新导入会产生新 ID，不继承旧谱的成绩。原文件备份在 `CustomChartMod/Backup/`。

安装包不含原游戏程序集。补丁在本机对用户已有的原程序集生成；不需要 MelonLoader、Python、Node 或第三方音游运行环境。安装脚本会拒绝未知游戏版本或被其他补丁修改的文件，防止覆盖不匹配的文件。Steam 验证完整性或更新可能撤销补丁；更新后需要重新验证适配。

## 实现

`Core.cs` 校验 JSON、保存曲库、生成 MUSYNX 谱面文本、读取 PCM。`Progress.cs` 原子保存独立成绩、最近 20 局和音效偏好。`GameChartMod.cs` 提供游戏内曲库和导入/切换操作，拦截蜡烛人的谱面读取和背景音乐播放，并用音频采样时钟驱动其游玩时间；其他曲目继续使用原来的加载流程。

`ImportHelper.cs` 用标准 Windows 文件选择窗口和 NAudio 解码 MP3/WAV，导入时转换为 PCM。`Patcher.cs` 添加运行时调用入口和自定义曲目的成绩保护。原项目关闭了 Unity 音频，安装同时开启该设置以播放自定义 PCM；原曲仍走 CRI。

曲库入口准备蜡烛人的 4 键简单槽位，然后调用官方选歌／开歌设置流程，由原版决定主题和场景。主题设置沿用游戏自身的全局偏好和已拥有内容，不按歌曲另存一份。原菜单不同难度的蜡烛人入口均使用当前选中的自定义谱。

判定、长条计数和评分直接使用原版 `BMSLib.JudgeGrade`，结算只调用一次 `GetSyncNumber`（它会清空部分累积值）。本局数值、最大连击和新纪录标记交还原版结算界面，最高分读取独立成绩。自定义局不调用原曲成绩写入或排行榜上传。原版同步率可能超过 100%，模组按原版百分比显示。

当前不支持 6 键制谱、游戏内谱面编辑、变 BPM 或独立 Key 音制作。

## 验证

已验证原游戏内通过导入助手加入两首音乐和三张谱面、同曲切谱、换歌后改变音频/时长/音符、暂停和倒计时续播、原生音频时钟同步、完整结算、重启保留曲库与选择，以及切回原曲。MP3 和 WAV 的解码流程均已运行。

自动验证程序调用与游戏内按钮相同的导入／切换／开歌操作，文件选择窗口使用测试路径。新增验证通过原生 `AddButton` 输入方法测试命中反馈和计分，并验证原版 2D／3D 场景、成绩隔离与落盘；不代表真人操作手感验收。原始日志和示例保存在项目 `artifacts/musynx-mod/`，测试程序只安装在测试副本，交付 Mod 不含自动操作探针。

## 从公开仓库构建

运行 `dependencies.ps1` 获取固定版本 NAudio 1.8.0 与 Mono.Cecil 0.11.6（官方 NuGet），再运行 `build.ps1 -GameRoot '你的 MUSYNX 目录'`。未指定目录时会查找 Steam 安装；构建需要本机正版游戏和已验证的原程序集，已安装 Mod 时会使用安装器备份。

运行 `package.ps1 -Archive` 生成 ZIP。示例音乐由 `tools/make-mod-examples.cjs` 从提交的 `examples/*.json` 与项目合成器生成，不需要测试游戏副本。`audio-config.json` 保存适配版本的音频设置校验信息。运行 `tests/run-core.ps1` 可单独验证格式、音频、曲库及成绩保存，无需原游戏。

源代码在当前项目的 `mods/ChartRecorder/`；安装包的 `Source/` 包含核心和安装源码。开源依赖及许可见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。

# Third-party dependencies

- **NAudio 1.8.0** by Mark Heath and contributors. Unmodified DLL used by the separate Windows import helper to decode audio. License: **Microsoft Public License (Ms-PL)**, included as `licenses/NAudio-LICENSE.txt`. Source: https://github.com/naudio/NAudio/tree/NAudio_1.8_Release
- **Mono.Cecil 0.11.6** by Jb Evain and contributors. Unmodified DLL used only by the installer patch generator. License: **MIT**, included as `licenses/Mono.Cecil-LICENSE.txt`. Source: https://github.com/jbevain/cecil/tree/0.11.6

The runtime calls the original game's existing MiniJSON parser. Original MUSYNX code, Unity DLLs, game resources, commercial music and a prepatched game assembly are not distributed in this package. The demo music is generated by this project's synthesizer.
